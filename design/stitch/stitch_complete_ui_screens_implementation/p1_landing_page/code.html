વાસ્તવિક પરિવર્તન • આણંદ પાયલટ સફળતા

"હવે દીકરીની સાયકલ અને સ્કોલરશિપ માટે એક પણ કાગળિયાની ઝેરોક્ષ કઢાવવી ન પડી."

આણંદ જિલ્લાના પેટલાદ તાલુકાના વાલી મહેશભાઈ પરમાર જણાવે છે કે વિદ્યા પ્રગતિ સેતુ દ્વારા માત્ર ફોન પર OTP આપીને તેમની દીકરીને ૧૫ મિનિટમાં સરસ્વતી સાધના સાયકલ અને નમો લક્ષ્મી યોજનાનો હપ્તો જમા થયો.

વારંવાર પૂછાતા પ્રશ્નો

સામાન્ય પ્રશ્નો અને જવાબો (FAQs)

યોજનાઓ માટે અરજી કરતી વખતે વિદ્યાર્થીઓ અને વાલીઓને મૂંઝવતા મુખ્ય મુદ્દાઓ.

ના, બિલકુલ નહીં. વિદ્યા પ્રગતિ સેતુની આ જ મુખ્ય વિશેષતા છે. તમે તમારા આધાર અથવા શાળા CTS ID થી લૉગિન કરો એટલે સિસ્ટમ તમારી યોગ્યતા મુજબની તમામ યોજનાઓ (નમો લક્ષ્મી, NMMS, સાયકલ વગેરે) એક જ સ્ક્રીન પર દર્શાવે છે અને તમે માત્ર એક ક્લિકમાં સંમતિ આપીને અરજી કરી શકો છો.
ભારત સરકાર અને ગુજરાત સરકારના નિયમો મુજબ તમામ શિષ્યવૃત્તિ હવે સીધા આધાર પેમેન્ટ બ્રિજ (PFMS DBT) મારફતે જમા થાય છે. આથી વિદ્યાર્થી કે તેના વાલીનું બેંક ખાતું આધાર કાર્ડ સાથે લિંક અને DBT-એક્ટિવ હોવું અનિવાર્ય છે. પોર્ટલ પર લૉગિન કરીને તમે તમારું DBT સ્ટેટસ પણ ચેક કરી શકો છો.
કોઈ ભૌતિક કાગળો આપવાની જરૂર નથી. ધોરણ ૯ માં નિયમિત પ્રવેશ મેળવનાર કન્યાને શાળા દ્વારા નિર્ધારિત દિવસે સાયકલ હેન્ડઓવર સમયે માત્ર વાલીના મોબાઈલ પર આવેલો ૬-આંકડાનો QR-OTP આચાર્યશ્રીને બતાવવાનો રહેશે. OTP દાખલ થતાં જ સાયકલ સોંપવામાં આવશે.
ડિજિલોકર સાથે પોર્ટલ જોડાયેલું હોવાથી રાજ્ય સરકારના ઈ-ગ્રામ અને જનસેવા કેન્દ્રના ડેટાબેઝમાંથી તાજેતરના પ્રમાણપત્રો સીધા જ ફેચ થઈ જાય છે. જો કોઈ વિસંગતતા જણાય તો તમે પોર્ટલ પરથી જ તાજા દાખલા માટે સીધી ઓનલાઈન વિનંતી મોકલી શકો છો.
