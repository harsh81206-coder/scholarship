# Bundled fonts

- `inter-latin-wght-normal.woff2`: Inter variable font, OFL 1.1. Source package: `@fontsource-variable/inter` 5.3.0.
- `noto-sans-gujarati-wght-normal.woff2`: Noto Sans Gujarati variable font, OFL 1.1. Source package: `@fontsource-variable/noto-sans-gujarati` 5.3.0.

The licenses are copied beside the font files. Both are loaded with `next/font/local`, so builds do not fetch fonts from the network.
